# Physics Lab Game — Decisions Log

Working title: **Physics Lab** (Roblox/Minecraft-style digital physics laboratory).
Started: 2026-10-09. Process: spec-driven design (brainstorm → spec → plan → implementation).

## Decided

| # | Date | Decision | Rationale |

| D2 | 2026-10-09 | MVP scope = **sandbox core + challenge layer** (enables "class demo" and "assigned lab practice"). Free-play progression is out of MVP. | Challenges are what universities pay for; progression is expensive game design. |

| D41 | 2026-10-09 | **dev-framework SECURITY applied to a client-only app.** Server sections (auth, sessions, SQL, SSRF, rate limiting, uploads to a server) do not apply. Applied: (a) challenge links/files and result files are **untrusted input** — byte-size cap before decompression, bounded inflate output, Zod parse at the load boundary, fail closed with the failing path (spec §7.6); (b) user and challenge text rendered as text only, never `dangerouslySetInnerHTML`; (c) CSV exports neutralize leading `=`, `+`, `-`, `@`, tab and CR (lands with CSV in M4); (d) CSPRNG (`crypto.getRandomValues`) for teacher seeds; (e) CI runs `pnpm install --frozen-lockfile` and `pnpm audit --audit-level high` as a gate, and every workflow declares `permissions: contents: read`; (f) Zod runs with `jitless: true`. **Deviation:** the CSP allows `'wasm-unsafe-eval'` in `script-src` (required to instantiate Rapier WASM; `'unsafe-eval'` stays banned), with `worker-src 'self'` and `connect-src 'self'`; in M1 it ships as a `<meta>` CSP because hosting headers are deferred (F16). | Defense in depth for files students and teachers exchange; WASM needs the narrow WASM-only CSP keyword. |
| D42 | 2026-10-09 | **Combined uncertainty includes the theory's propagated input uncertainty** (refines spec §7.3): `u_c = sqrt(u_meas² + u_theory² + (tol_model · theory)²)`, where `u_theory` propagates the uncertainties of the measured inputs the student used through the solver (central differences). A prediction passes when `|prediction − measurement| ≤ k · u_c`. | Without `u_theory`, noisy input measurements (e.g. photogate speed) would fail correct predictions; this matches lab error-propagation practice. |
| D43 | 2026-10-09 | **Rapier package: `@dimforge/rapier3d-deterministic-compat`, pinned exactly (0.21.0)** (refines D16). Same deterministic build with the WASM inlined as base64, so one adapter loads identically in Node/Vitest, Web Workers and browser tests without bundler WASM plugins. The engine id string (package@version) is recorded in every result. | About 33 % more WASM bytes, well inside the 15 MB budget (D19); removes a whole class of loader differences between environments. |
| D44 | 2026-10-09 | **M1 catapult mechanics and run model.** (a) The arm is a motor-driven hinge holding the ball with a fixed joint; a new core world element, the **angle latch**, removes the fixed joint and brakes the motor once the hinge reaches its release angle (challenge parameter `releaseHingeAngle` 75–105° → launch angle 30–60°). Hinge limits move to M2; the brake replaces them in M1. (b) **Calibration run:** the first launch auto-pauses at release so students measure release speed (photogate over the ball diameter), angle (protractor) and height (ruler) before predicting; range and time measurements stay locked until every prediction is submitted; the run then continues from the pause. (c) Command-log entries record `atStep` (run-local step index); replay steps to each entry before applying it. (d) Landing contact is refined inside the contact step by ballistic interpolation from the pre-step state. | Predict → observe needs measurable launch conditions without revealing the landing; `atStep` makes the log a complete, replayable description of a run. |
| D45 | 2026-10-09 | **New core package `@physics-lab/det-math`** (seeded PRNG, deterministic trigonometry and logarithm, hashing) used by `sim-core` and `instruments` (extends the spec §4 graph). The portability and determinism rules apply to it. | `instruments` needs seeded Gaussian noise but must not depend on `sim-core`; duplicating deterministic math would split the single source of truth. |
